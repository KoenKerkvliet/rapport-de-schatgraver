# Rapport De Schatgraver

Hulpmiddel voor leerkrachten van basisschool De Schatgraver om een puntloos rapport ("Zo ontwikkel ik mij") in te vullen, te printen en als PDF te bewaren.

**Open de tool:** https://koenkerkvliet.github.io/rapport-de-schatgraver/

## Privacy (AVG)
- De tool draait volledig in de browser. Er is geen server en geen database.
- Gegevens van kinderen blijven in de browser van het apparaat en worden niet verstuurd.
- De tool maakt geen verbinding met internet (de lettertypen zitten in het bestand).
- Een klas bewaren of openen gaat via een bestand dat je zelf downloadt (*Klas bewaren*). Bewaar dat alleen op een door de school goedgekeurde plek.
- Zet nooit een klasbestand (.json) of leerlingenlijst (.csv) in deze repository.
